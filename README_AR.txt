SHADOW CARD LAB V99 — المرحلة الثانية
======================================

ما الذي تضيفه هذه النسخة؟
- Backend باستخدام Node.js وExpress.
- جلسة Checkout مستضافة لدى Stripe في TEST MODE فقط.
- مبلغ ثابت للاختبار: 1.00 USD.
- جلب حالة جلسة الدفع من Stripe.
- استقبال Webhooks والتحقق من توقيع Stripe.
- سجل أحداث محلي بصيغة JSON.
- لا يستقبل الموقع PAN أو CVV ولا يولّد أرقام بطاقات ولا يختبر أرقام BIN عشوائية.

متطلبات التشغيل:
- Node.js 18 أو أحدث.
- حساب Stripe Developer للحصول على مفتاح اختبار يبدأ بـ sk_test_.
- لا تستخدم مفاتيح Live.

التشغيل محلياً:
1) فك ضغط المشروع.
2) افتح الطرفية داخل مجلد المشروع.
3) نفّذ: npm install
4) انسخ .env.example إلى ملف باسم .env.
5) ضع مفتاح Stripe TEST في STRIPE_SECRET_KEY.
6) أبقِ APP_BASE_URL=http://localhost:3000
7) نفّذ: npm start
8) افتح: http://localhost:3000

إعداد Webhook محلياً:
- ثبّت Stripe CLI من موقع Stripe الرسمي.
- شغّل: stripe listen --forward-to localhost:3000/api/stripe/webhook
- انسخ قيمة whsec_ التي يعرضها CLI إلى STRIPE_WEBHOOK_SECRET في .env.
- أعد تشغيل الخادم.

بطاقة الاختبار:
- رقم الاختبار الشائع للنجاح: 4242 4242 4242 4242
- تاريخ مستقبلي، وأي CVC من 3 أرقام.
- هذه بيانات اختبار Stripe فقط، وليست بطاقة حقيقية.
- اختبر حالات الرفض باستخدام بطاقات الاختبار الموثقة لدى Stripe.

النشر:
- انشر التطبيق على خادم HTTPS.
- عيّن APP_BASE_URL إلى عنوان HTTPS الفعلي.
- أضف Webhook endpoint: https://YOUR-DOMAIN/api/stripe/webhook
- عيّن STRIPE_WEBHOOK_SECRET الذي يصدره Stripe لذلك الـ endpoint.
- خزّن الأسرار في متغيرات بيئة منصة الاستضافة، ولا ترفع .env إلى Git.

تنبيه مهم:
Stripe لا يضمن فتح حساب تاجر Live لشركة مسجلة في كل دولة. هذا المشروع يختبر Test Mode فقط. توفر الدفع الحقيقي يعتمد على أهلية بلد الشركة وموافقة مزود الدفع.
لا تستخدم هذا النظام لتجربة بطاقات مولّدة أو بطاقات لا تملكها أو لا تملك تفويضاً صريحاً لاستخدامها.
